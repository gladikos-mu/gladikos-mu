# Usability Buddy Backend

Ein einfaches Flask-Backend zur Anbindung deines OpenAI Assistants.

## Setup

1. `.env.example` kopieren und umbenennen in `.env`
2. Trage deinen OpenAI API-Key & Assistant-ID ein
3. In der Konsole (Windows CMD oder PowerShell):

```bash
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
python app.py
